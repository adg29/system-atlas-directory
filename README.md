# system-atlas-directory

Interactive [System Atlas](https://github.com/inkboard/system-atlas) of [yc-software/qm](https://github.com/yc-software/qm).

- [index.html](./index.html) — clickable isometric map
- [SYSTEM.md](./SYSTEM.md) — text twin, generated from the same data
- [atlas/data.mjs](./atlas/data.mjs) — the only file to edit; rebuild with `node atlas/build.mjs`

Live: https://adg29.github.io/system-atlas-directory/
